# PHP Lab Project

[![PHP CI Application](https://github.com/KaterynaSeniv/phplab/actions/workflows/phplab.yml/badge.svg)](https://github.com/KaterynaSeniv/phplab/actions/workflows/phplab.yml)

## Опис та функціонал
Цей проєкт є навчальним додатком на PHP із налаштованим CI/CD пайплайном за допомогою GitHub Actions.

Основний функціонал:
* Базовий сервіс калькулятора (`Calculator.php`) для виконання арифметичних операцій.
* Автоматизований лінтинг коду за допомогою **Laravel Pint** відповідно до стандартів PSR-12.
* Модульні тести на базі **PHPUnit**.
* Автоматична перевірка та збірка коду при кожному push та pull request.
